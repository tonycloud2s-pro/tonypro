# คำนวณกำไรโปรโมชั่นร้านอาหาร (Grab / LINE MAN)

เว็บแอปพลิเคชันสำหรับเจ้าของร้านอาหารไทยขนาดเล็ก ช่วยคำนวณกำไรสุทธิ จุดคุ้มทุน วิเคราะห์เงื่อนไขโปรโมชั่นของแอป และวิเคราะห์กำไรรายเมนูเมื่อจัดโปรโมชั่นเดลิเวอรีบน Grab Food และ LINE MAN ได้อย่างแม่นยำ 100%

---

## 🌟 คุณสมบัติเด่น (Features)

1. **ฟรี 100% ไม่มีค่าใช้จ่ายแอบแฝง**:
   - ไม่ต้องใช้ API Key ใดๆ ในการทำงานหลัก
   - ไม่มีการเรียกใช้ AI API หรือระบบหลังบ้านที่เสียเงิน
   - ทำงานแบบออฟไลน์ 100% แม้ไม่มีอินเทอร์เน็ต
2. **เก็บข้อมูลในเครื่องของคุณ (Privacy First)**:
   - ข้อมูลต้นทุน ราคา และรายการอาหารทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์
   - ปลอดภัย ข้อมูลไม่ถูกส่งออกไปเซิร์ฟเวอร์ภายนอก
   - มีระบบสำรองข้อมูล (Export/Import JSON) สำหรับย้ายเครื่องหรือกันข้อมูลหาย
3. **วิเคราะห์เงื่อนไขโปรของแอป (Promotion Terms Analyzer)** (ใหม่ใน v2):
   - คัดลอกข้อความเงื่อนไขแคมเปญจาก Grab / LINE MAN มาวาง
   - ระบบดึงส่วนลด, เพดานลดสูงสุด, ยอดสั่งขั้นต่ำ, ใครเป็นผู้รับผิดชอบส่วนลด (ร้าน vs แอป), GP พิเศษ, สัญญาผูกมัด (Price Parity, ห้ามขึ้นราคา, บทลงโทษยกเลิก)
   - คำนวณความคุ้มค่า (Verdict: คุ้ม / คุ้มถ้ายอดเพิ่มถึง X% / ไม่คุ้ม)
   - แจกแจงข้อดี ข้อเสีย และความเสี่ยง พร้อมปุ่มคัดลอกคำสั่งสำหรับนำไปถาม AI ต่อได้ฟรี
4. **นำเข้าเมนูขั้นสูง & แดชบอร์ดวิเคราะห์กำไรรายเมนู** (ใหม่ใน v2):
   - รองรับไฟล์ Excel (.xlsx, .xls) และ CSV พร้อมข้ามหัวตารางซ้อน/แบนเนอร์อัตโนมัติ
   - คัดกรองตัวเลข ตัดเครื่องหมาย ฿ ลูกน้ำ ช่องว่างอัตโนมัติ
   - ตรวจสอบรายการซ้ำ ข้ามแถวผิดปกติ และดาวน์โหลดรายงานข้อผิดพลาดเป็น CSV
   - **แดชบอร์ดวิเคราะห์กำไรรายเมนู (Menu Analysis Dashboard)**: ทดลองจัดโปรลด X% ให้เห็นผลกระทบของทุกเมนูพร้อมกัน, แสดงตัวคูณราคา (Markup), จุดคุ้มทุน และราคาแนะนำเพื่อให้ได้กำไรเทียบเท่าหน้าร้าน
5. **รองรับโปรโมชั่นเดลิเวอรียอดนิยม 3 รูปแบบ**:
   - **เซ็ตรวมราคา (Combo Set)**: เลือกเมนูจับคู่ แล้วตั้งราคาเซ็ตที่ลูกค้าจ่าย
   - **ลดเป็น %**: พร้อมตัวเลือกจำกัดส่วนลดสูงสุด (บาท) และยอดสั่งขั้นต่ำ
   - **ซื้อครบแถมเครื่องดื่ม/ของแถมฟรี**: คิดต้นทุนของแถมจริง และตั้งค่า GP ของแถมได้
6. **คำนวณอย่างโปร่งใส ตรวจสอบได้ทุกบรรทัด**:
   - แสดงตารางลำดับขั้น: ราคาตั้ง (P) → ยอดลูกค้าจ่าย → ฐาน GP → ค่า GP → VAT 7% → ค่าธุรกรรม → รายได้สุทธิที่ได้รับจริง → ต้นทุนวัตถุดิบและบรรจุภัณฑ์ → กำไรสุทธิ (บาท และ %)
   - เปรียบเทียบกับกำไรขายหน้าร้าน (Dine-in) ว่าขายแอปได้เงินต่างกันเท่าใด
   - คำนวณ **ราคาต่ำสุดที่ไม่ขาดทุน (จุดคุ้มทุน)** และ **ราคาแนะนำเพื่อให้ได้กำไรตามเป้า**
7. **ระบบเตือนต้นทุนจริง**:
   - หากเมนูใดยังไม่ได้กรอกต้นทุน ระบบจะขึ้นเตือน "ยังไม่มีต้นทุน" และปฏิเสธการคำนวณกำไรเงียบๆ เพื่อป้องกันการตัดสินใจผิดพลาด

## 📊 โครงสร้างข้อมูลที่ระบบนำเข้าเข้าใจ (Data Format Specification)

ระบบนำเข้าไฟล์ Excel และ CSV รองรับข้อมูลดังต่อไปนี้:

| ความจำเป็น | ชื่อคอลัมน์ (ภาษาไทย/อังกฤษที่รองรับ) | ตัวอย่างข้อมูล | คำอธิบาย |
|---|---|---|---|
| **จำเป็น (Required)** | ชื่อเมนู, เมนู, รายการอาหาร, name, menu | ข้าวกะเพราหมูสับ | ชื่อกลุ่มอาหารหลัก |
| **จำเป็น (Required)** | ราคาหน้าร้าน, ราคาร้าน, ปกติ, dine in, store price | 70 | ราคาขายสดหน้าร้าน (บาท) |
| **จำเป็น (Required)** | ต้นทุนอาหาร, ต้นทุน, cost, food cost | 26 | ต้นทุนวัตถุดิบจริงต่อจาน (บาท) |
| **แนะนำอย่างยิ่ง (Strongly Recommended)** | ตัวเลือก, ประเภท, option, variant, protein | ไข่ดาว / พิเศษ | รายละเอียดตัวเลือกย่อย |
| **แนะนำอย่างยิ่ง (Strongly Recommended)** | หมวดหมู่, หมวด, category | อาหารจานเดียว | กลุ่มประเภทอาหาร |
| **แนะนำอย่างยิ่ง (Strongly Recommended)** | ราคาGrab, grab, grab price | 90 | ราคาตั้งบน Grab ก่อนลด (บาท) |
| **แนะนำอย่างยิ่ง (Strongly Recommended)** | ราคาLineman, lineman, LINE MAN | 90 | ราคาตั้งบน LINE MAN ก่อนลด (บาท) |
| **แนะนำอย่างยิ่ง (Strongly Recommended)** | บรรจุภัณฑ์, กล่อง, packaging, pack cost | 4 | ค่ากล่อง ถุง ช้อน (บาท) |
| **ข้อมูลเสริม (Optional)** | พิเศษ, add-on, addon | 15 | ราคาตัวเลือกพิเศษ/ท็อปปิ้ง |

> 💡 **หมายเหตุ**: หากไฟล์ไม่มีราคา Grab หรือ LINE MAN สามารถเปิดตัวเลือก **"ตั้งราคาแอปประมาณ = ราคาหน้าร้าน × ตัวคูณ"** ในหน้าจอนำเข้าได้

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ใช้งานแบบดาวน์โหลดไฟล์เดียว (ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่อเน็ต)
1. เมื่อทำการ Build จะได้ไฟล์ `dist/index.html` เพียงไฟล์เดียว (Single File)
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Safari, Edge)
3. ใช้งานได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต!

### วิธีที่ 2: รันบนเครื่องคอมพิวเตอร์ของคุณ (Local Development)
```bash
# ติดตั้งไลบรารี
npm install

# รันโหมดทดสอบ
npm run dev

# รัน Unit Test ตรวจสอบสูตรคำนวณ
npm test

# Build เป็น Single File HTML
npm run build
```

## 🌐 วิธีนำขึ้นใช้งานฟรีบน GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub (ตั้งชื่อตามต้องการ เช่น `food-promo-calculator`)
   > ⚠️ **ข้อควรระวัง**: หากตั้งเป็น Public Repository อย่าฝังราคาต้นทุนจริงไว้ในซอร์สโค้ด (แอปนี้ออกแบบให้เก็บข้อมูลต้นทุนในเครื่องของผู้ใช้ผ่านเบราว์เซอร์เท่านั้น)
2. อัปโหลดโค้ดทั้งหมดขึ้น Branch `main` หรือ `master`
3. ไปที่ GitHub Repository ของคุณ:
   - เมนู **Settings** → เมนูย่อย **Pages**
   - ในหัวข้อ **Build and deployment** > **Source**:
     - **วิธีที่แนะนำที่สุด (สำเร็จทันที)**: เลือก **`Deploy from a branch`** → Branch: **`main`** (หรือ `master`) → โฟลเดอร์: **`/docs`** → กด **Save**
     - **หรือวิธีใช้ GitHub Actions**: เลือก Source เป็น **`GitHub Actions`** แล้วรอ workflow รันเสร็จ
4. รอประมาณ 30-60 วินาที จะได้ลิงก์เว็บสำหรับเปิดใช้งานได้ฟรี 24 ชม. ทั้งบนมือถือและคอมพิวเตอร์!

### ⚠️ กรณีเปิดหน้าเว็บแล้วเจอหน้าจอขาว (Blank Page Troubleshooting)
- **หากเลือก Source เป็น Deploy from a branch**: ให้ตรวจดูว่าเลือกโฟลเดอร์เป็น **`/docs`** หรือไม่ (หากเผลอเลือก `/(root)` ตัวระบบจะ redirect ไปยัง `/docs/index.html` ให้อัตโนมัติ แต่แนะนำให้เลือกโฟลเดอร์ `/docs` ใน Settings จะดีที่สุด)
- **หากเลือก Source เป็น GitHub Actions**: อย่าลืมเปิดสิทธิ์ Workflow permissions เป็น "Read and write permissions" ใน Settings → Actions → General
- **ประเภท Repository**: สำหรับบัญชี GitHub แบบฟรี Repository ต้องตั้งเป็น **Public** เท่านั้นจึงจะใช้ Pages ได้ฟรี (ถ้า Private ต้องอัปเกรดแผน)
- **ตรวจสอบ Console**: หากหน้าจอยังคงขาว ให้กดปุ่ม `F12` ในเบราว์เซอร์ แล้วเลือกแท็บ **Console** เพื่อดูข้อความแจ้งเตือนสีแดง และสามารถกดส่งออกข้อมูลสำรองผ่านหน้าจอ Error Boundary ได้

## 💾 วิธีสำรองและย้ายข้อมูล (Backup & Restore)

1. เข้าไปที่แท็บ **"นำเข้า/สำรองข้อมูล"**
2. กดปุ่ม **"ส่งออกข้อมูลสำรอง (ดาวน์โหลด JSON)"** เพื่อบันทึกไฟล์เก็บไว้ในคอมพิวเตอร์ หรือส่งเข้า LINE ส่วนตัว
3. หากต้องการย้ายไปใช้บนมือถือหรือเครื่องอื่น ให้เปิดเว็บในเครื่องใหม่ แล้วกด **"กู้คืนข้อมูลจากไฟล์สำรอง (JSON)"** แล้วเลือกไฟล์ที่ดาวน์โหลดไว้ ข้อมูลทั้งหมดจะกลับมาทันที
