# คำนวณกำไรโปรโมชั่นร้านอาหาร (Grab / LINE MAN)

เว็บแอปพลิเคชันสำหรับเจ้าของร้านอาหารไทยขนาดเล็ก ช่วยคำนวณกำไรสุทธิ จุดคุ้มทุน และผลกระทบต่อต้นทุนจากการจัดโปรโมชั่นเดลิเวอรีบน Grab Food และ LINE MAN ได้อย่างแม่นยำ 100%

---

## 🌟 คุณสมบัติเด่น (Features)

1. **ฟรี 100% ไม่มีค่าใช้จ่ายแอบแฝง**:
   - ไม่ต้องใช้ API Key
   - ไม่มีการเรียกใช้ AI API หรือระบบหลังบ้านที่เสียเงิน
   - ทำงานแบบออฟไลน์ 100% แม้ไม่มีอินเทอร์เน็ต
2. **เก็บข้อมูลในเครื่องของคุณ (Privacy First)**:
   - ข้อมูลต้นทุน ราคา และรายการอาหารทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์
   - ปลอดภัย ข้อมูลไม่ถูกส่งออกไปเซิร์ฟเวอร์ภายนอก
   - มีระบบสำรองข้อมูล (Export/Import JSON) สำหรับย้ายเครื่องหรือกันข้อมูลหาย
3. **รองรับโปรโมชั่นเดลิเวอรียอดนิยม 3 รูปแบบ**:
   - **เซ็ตรวมราคา (Combo Set)**: เลือกเมนูจับคู่ แล้วตั้งราคาเซ็ตที่ลูกค้าจ่าย
   - **ลดเป็น %**: พร้อมตัวเลือกจำกัดส่วนลดสูงสุด (บาท) และยอดสั่งขั้นต่ำ
   - **ซื้อครบแถมเครื่องดื่ม/ของแถมฟรี**: คิดต้นทุนของแถมจริง และตั้งค่า GP ของแถมได้
4. **คำนวณอย่างโปร่งใส ตรวจสอบได้ทุกบรรทัด**:
   - แสดงตารางลำดับขั้น: ราคาตั้ง (P) → ยอดลูกค้าจ่าย → ฐาน GP → ค่า GP → VAT 7% → ค่าธุรกรรม → รายได้สุทธิที่ได้รับจริง → ต้นทุนวัตถุดิบและบรรจุภัณฑ์ → กำไรสุทธิ (บาท และ %)
   - เปรียบเทียบกับกำไรขายหน้าร้าน (Dine-in) ว่าขายแอปได้เงินต่างกันเท่าใด
   - คำนวณ **ราคาต่ำสุดที่ไม่ขาดทุน (จุดคุ้มทุน)** และ **ราคาแนะนำเพื่อให้ได้กำไรตามเป้า**
5. **นำเข้าเมนูง่ายจาก Excel (.xlsx) และ CSV**:
   - มีระบบจับคู่คอลัมน์อัตโนมัติ (Column Mapping)
   - เลือกชีตใน Excel ได้ (เช่น ชีต "Grab - Lineman")
   - มีปุ่มดาวน์โหลดเทมเพลต CSV ภาษาไทยที่สะอาด
6. **ระบบเตือนต้นทุนจริง**:
   - หากเมนูใดยังไม่ได้กรอกต้นทุน ระบบจะขึ้นเตือน "ยังไม่มีต้นทุน" และปฏิเสธการคำนวณกำไรเงียบๆ เพื่อป้องกันการตัดสินใจผิดพลาด
7. **ฟีเจอร์จำลองกำไรต่อเดือน**:
   - ใส่จำนวนออเดอร์ที่คาดว่าจะขายได้ต่อวัน ระบบจะคำนวณประมาณการกำไรรวมตลอดทั้งเดือนของแต่ละโปรโมชั่น

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ใช้งานแบบดาวน์โหลดไฟล์เดียว (ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่อเน็ต)
1. เมื่อทำการ Build จะได้ไฟล์ `dist/index.html` เพียงไฟล์เดียว (Single File)
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Safari, Edge)
3. ใช้งานได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต!

### วิธีที่ 2: รันบนเครื่องคอมพิวเตอร์ของคุณ (Local Development)
```bash
# ติดตั้งไลบรารี
npm install

# รันโหมดทดสอบ
npm run dev

# รัน Unit Test ตรวจสอบสูตรคำนวณ
npm test

# Build เป็น Single File HTML
npm run build
```

## 🌐 วิธีนำขึ้นใช้งานฟรีบน GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub (ตั้งชื่อตามต้องการ เช่น `food-promo-calculator`)
   > ⚠️ **ข้อควรระวัง**: หากตั้งเป็น Public Repository อย่าฝังราคาต้นทุนจริงไว้ในซอร์สโค้ด (แอปนี้ออกแบบให้เก็บข้อมูลต้นทุนในเครื่องของผู้ใช้ผ่านเบราว์เซอร์เท่านั้น)
2. อัปโหลดโค้ดทั้งหมดขึ้น Branch `main`
3. ไปที่ GitHub Repository ของคุณ:
   - เมนู **Settings** → เมนูย่อย **Pages**
   - ในหัวข้อ **Build and deployment** > **Source**: เลือกเป็น **GitHub Actions**
4. ระบบจะรันไฟล์ `.github/workflows/deploy.yml` ให้อัตโนมัติ เมื่อเสร็จแล้วคุณจะได้รับลิงก์เว็บสำหรับเปิดใช้งานได้ฟรี 24 ชม. ทั้งบนมือถือและคอมพิวเตอร์

## 💾 วิธีสำรองและย้ายข้อมูล (Backup & Restore)

1. เข้าไปที่แท็บ **"นำเข้า/สำรองข้อมูล"**
2. กดปุ่ม **"ส่งออกข้อมูลสำรอง (ดาวน์โหลด JSON)"** เพื่อบันทึกไฟล์เก็บไว้ในคอมพิวเตอร์ หรือส่งเข้า LINE ส่วนตัว
3. หากต้องการย้ายไปใช้บนมือถือหรือเครื่องอื่น ให้เปิดเว็บในเครื่องใหม่ แล้วกด **"กู้คืนข้อมูลจากไฟล์สำรอง (JSON)"** แล้วเลือกไฟล์ที่ดาวน์โหลดไว้ ข้อมูลทั้งหมดจะกลับมาทันที

สูตรคำนวณถูกแยกเป็น Pure Functions ใน `src/lib/calc.ts` และผ่านการทดสอบครอบคลุมทุกกรณีใน `src/lib/calc.test.ts`:
- **กรณี A**: P = 52, ลด 10%, ต้นทุน 28 → ลูกค้าจ่าย 46.80, ค่า GP 14.04, รายได้สุทธิ 32.76, กำไร 4.76 ฿ (ผ่าน ✓)
- **กรณี B**: P = 220, เซ็ต 200, ต้นทุน 118, VAT 0% → ค่า GP 59.40, รายได้สุทธิ 140.60, กำไร 22.60 ฿ (ผ่าน ✓)
- **กรณี C**: เหมือน B แต่ VAT GP 7% → VAT 4.158, รายได้สุทธิ 136.442, กำไร 18.442 ฿ (ผ่าน ✓)
- **กรณี D**: เหมือน B แต่ GP คิดจากราคาหลังลด → ค่า GP 54.00, รายได้สุทธิ 146.00, กำไร 28.00 ฿ (ผ่าน ✓)
